# Website

Static site published to <https://elyos-racing.github.io/team-portfolio/> by `.github/workflows/pages.yml` on every push to `main`.

```bash
pip install markdown pyyaml
python site/build.py                 # → _site/
python site/build.py --write-readme  # rewrite the README results table from data.yaml
```

| File | What it is |
|---|---|
| `data.yaml` | Single source for the home page, the two competitions and the results table (README included) |
| `tracks.json` | Course outlines: Indianapolis Motor Speedway (Mileage) and Silesia Ring (ADC), from the official Shell Eco-marathon coordinates as processed by the team's track pipelines |
| `assets/` | Logo, favicon and share card, generated by `tools/brand_assets.py` from the official white logo |
| `style.css`, `site.js` | Styles and the one scroll effect (results bars) |

## Brand kit

| Token | Hex | Use |
|---|---|---|
| Navy | `#0F3854` | From the logo: titles, accents on light backgrounds |
| Deep navy | `#08202F` | Header, hero and footer |
| Silver | `#E4E4E4` | From the logo: rules and light surfaces |
| Page | `#F2F3F4` | Content background |
| Signal blue | `#5E97FF` | Course outlines, bars and the logo's navy arm on dark backgrounds |
| Checkered | black and white | Only at the start/finish line |

Type: Archivo, width 125 for headlines (echoes the extended ELYOS wordmark) and width 100 for text. Motion: the course draws itself once in the hero, and the results bars fill once when they come into view; everything respects reduced motion.
