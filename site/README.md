# Website

Static site published to <https://elyos-racing.github.io/team-portfolio/> by `.github/workflows/pages.yml` on every push to `main`.

```bash
pip install markdown pyyaml
python site/build.py                 # → _site/
python site/build.py --write-readme  # rewrite the README results table from data.yaml
```

| File | What it is |
|---|---|
| `data.yaml` | Single source for the home page, the two competitions and the results table (README included) |
| `tracks.json` | Course outlines: Indianapolis Motor Speedway (Mileage) and Silesia Ring (ADC), from the official Shell Eco-marathon coordinates as processed by the team's track pipelines |
| `assets/` | Logo, favicon and share card, generated by `tools/brand_assets.py` from the official white logo |
| `style.css`, `site.js` | Styles and the results-bars effect |
| `hero3d.js` | 3D hero (three.js from unpkg): the 2026 car in x-ray on the start line; scrolling orbits it and then follows it around the course. Static outline without WebGL; still with reduced motion or the pause button. `?hero=0.5` pins the scroll progress for screenshots |
| `assets/car.glb` | The 2026 car (also the ADC kit base), from the team's SolidWorks assembly exported to glTF and converted with gltf-transform: fasteners removed, simplified and meshopt-compressed (≈ 0.8 MB, 130 k triangles) |

## Accessibility

Skip link, `main` and `nav` landmarks, visible focus, 44 px touch targets in the header, text alternatives for the course outlines and the 3D animation (the canvas itself is hidden from assistive technology), reduced motion respected everywhere, a pause button for the 3D motion (remembered between visits), forced-colors support, and contrast of at least 4.5:1 for body text on both themes.

Type: Archivo, width 125 for headlines (echoes the extended ELYOS wordmark) and width 100 for text. Motion: the course draws itself once in the hero, and the results bars fill once when they come into view; everything respects reduced motion.
